# 🎬 Movie Recommender System

A **Movie Recommendation System** built using **Python** and **Streamlit**, which suggests movies based on your selection and shows their posters using **TMDB API**. Missing posters are automatically replaced with a custom placeholder image for a professional look.  

This project is perfect for learning recommendation systems, API integration, and building interactive web apps.

---

## 📝 Features

- Search and select a movie from a dropdown.  
- Get **top 5 recommended movies** based on similarity.  
- Display movie posters using **TMDB API**.  
- Automatically handles missing posters with a **custom placeholder image**.  
- Stable and fast: uses caching to avoid repeated API calls.  
- Professional UI built with **Streamlit**.
